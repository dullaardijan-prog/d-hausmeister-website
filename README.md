# AD Hausmeisterservice – Vercel-Deployment

Dieser Ordner ist die vollständige Website. `index.html`, `vercel.json`,
`robots.txt` und der komplette Ordner `assets` müssen gemeinsam in das
GitHub-Repository hochgeladen werden.

## Veröffentlichung

1. Auf GitHub ein neues leeres Repository anlegen.
2. Den Inhalt dieses Ordners in die oberste Ebene des Repositorys hochladen.
3. Auf Vercel anmelden und **Add New → Project** wählen.
4. Das GitHub-Repository importieren.
5. Framework Preset auf **Other** lassen; Root Directory ist `./`.
6. Keine Build- oder Output-Einstellungen eintragen und **Deploy** wählen.

Vercel vergibt anschließend automatisch eine Adresse wie
`projektname.vercel.app`. Jeder spätere Push auf den Produktionsbranch löst
automatisch ein neues Deployment aus.

## Nach dem ersten Deployment

- Die Website und alle Bilder auf Desktop und Smartphone prüfen.
- Das Kontaktformular einmal absenden. FormSubmit kann beim ersten Einsatz eine
  Bestätigungs-E-Mail an `ad.hausmeisterservice@outlook.de` senden; diese muss
  bestätigt werden, bevor Anfragen zugestellt werden.
- Sobald eine endgültige Domain oder Vercel-URL feststeht, sollten die
  Social-Media- und SEO-URLs abschließend auf diese Adresse festgesetzt werden.
